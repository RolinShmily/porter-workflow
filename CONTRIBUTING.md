# Contributing

All contributor documentation lives in [`docs/`](docs/development.md) so rules are maintained in one place:

- **Setup, four gates, extending, licence rules & release**: [`docs/development.md`](docs/development.md)
- **Architecture & layers**: [`docs/architecture.md`](docs/architecture.md)
- **Design principles & WebUI baseline**: [`docs/design.md`](docs/design.md)
- **Public Python API & config reference**: [`docs/reference.md`](docs/reference.md)

## Submitting changes

1. Fork and branch from `main`; open an issue first for non-trivial changes.
2. Run the four gates in [`docs/development.md`](docs/development.md) before opening a PR.
3. Follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`).
4. Never paste real API keys, cookies, or session tokens into issues or PRs.

By contributing, you agree that your contributions are licensed under the [MIT License](LICENSE).
